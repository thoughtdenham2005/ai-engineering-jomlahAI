# Responsible AI Risk

| Responsible AI Risk | Requirement | Measurement Method | Metric | Threshold |
| :--- | :--- | :--- | :--- | :--- |
| **RAI 1: Fairness** | The system shall ensure balanced data representation and equal retrieval quality across different demographic segments (e.g., MyKad local citizen rates vs. non-MyKad foreign tourist rates) and geographic regions within Malaysia (e.g., Klang Valley hubs vs. outer state destinations) without systematically favoring high-commercial landmarks over public/cultural sites. | Perform slice-based evaluation using a test suite of 40 location queries split equally between local/foreign pricing contexts and major/secondary tourist zones, measuring retrieval accuracy across slices. | Disparity Ratio (True Positive Rate Disparity across subgroup slices) | Disparity Ratio between 0.80 and 1.25 across all geographic and demographic test slices |
| **RAI 2: Safety / Scope** | The system shall strictly reject out-of-scope prompts (e.g., non-Malaysian destinations) and enforce safety guardrails to block harmful, dangerous, or emergency/legal advice generation (e.g., unauthorized cross-border visa advice or emergency evacuation routes). | Submit a benchmark suite of 30 adversarial, out-of-scope, and safety-violating test prompts (e.g., cross-border Singapore routes, emergency medical queries) and monitor system guardrail response flags. | Scope Violation & Safety Failure Rate (Percentage of unsafe or out-of-scope queries executed without fallback rejection) | 0% Safety Violations and 100% Out-of-Scope Fallback Rejection Rate. |
| **RAI 3: Privacy** | The system shall ensure that no Personally Identifiable Information (PII) or sensitive user context (e.g., exact user geolocation, saved full names, or payment details) is logged, exposed, or transmitted to third-party LLM APIs. | Audit API payload logs and database network traffic using static log scanning tools (e.g., Presidio or regex PII checkers) during live session testing | PII Leakage Rate (Number of unanonymized user data fields detected in outbound API requests or local vector logs) | 0 PII Leakage Instances (100% compliance with zero-retention policies). |
| **RAI 4: Transparency / Grounding** | The system shall explicitly cite the underlying document source (e.g., official PDF page number or public fare chart link) for all generated price estimates, operating hours, and transit schedules, explicitly flagging unverified nodes to the user. | Execute an automated RAG evaluation framework (e.g., Ragas or TruLens) on an evaluation dataset of generated itineraries to compare generated claims against retrieved context sources. | Faithfulness & Citation Recall Score (Percentage of generated claims supported by explicit context source citations) | >=90 Faithfulness Score and 100% Source Citation Coverage for all price and operating hour statements. |
