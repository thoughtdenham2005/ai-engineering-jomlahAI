# Evaluation Criteria

| Requirement ID | What does this requirement need? | Architecture Response |
| :--- | :--- | :--- |
| **FR-2 / RAI-4**<br>(Document-Grounded Information Retrieval & Transparency) | Accurate extraction of local pricing (MyKad vs. non-MyKad tiers), operating hours, and visit durations directly from verified Malaysian travel documents without hallucinating ungrounded numbers. | **RAG Pipeline & Vector DB:** Integrates a LangChain/LlamaIndex retrieval pipeline with a ChromaDB vector store to index official Malaysian tourism PDFs and transport fare guides, combined with strict system prompt grounding that enforces source citation. |
| **FR-4 / NFR-1**<br>(Dynamic Route/Budget Recalculation & Latency) | Real-time recalculation of total trip cost, transit time, and travel distances whenever activity nodes are added, reordered, connected, or deleted on the flowchart. | **Client-Side Graph Computation Engine:** Implements a lightweight topological pathfinding engine within the Flutter app state, calculating edge weights (distances and fares) locally to deliver instantaneous <=500ms visual canvas updates without round-trip API delays. |
| **FR-1 / RAI-2**<br>(Query Processing & Scope Enforcement) | Parsing natural language travel queries while enforcing strict geographical boundaries to block and reject out-of-scope or high-risk requests. | **Pre-Routing Guardrail & Intent Classifier:** Incorporates an entry-level query classifier (using guardrail logic like NeMo Guardrails) to filter out non-Malaysian destinations, out-of-bounds locations, or high-risk topics prior to reaching the LLM orchestrator. |
